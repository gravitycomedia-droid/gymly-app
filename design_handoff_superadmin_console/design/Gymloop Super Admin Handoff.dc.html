GYMLOOP · SUPER ADMIN CONSOLE · HANDOFF v1 · 24 SEP 2026

A calm, data-dense admin console that works as well on a phone as on a desktop.

Every frame on this board is the live prototype (Gymloop Console) mounted at a fixed width — what you see is what the clickable build does. Click anything inside a frame; each frame keeps its own state.

Assumptions
  • No Gymloop brand tokens were provided (the attached design system is empty), so this proposes a system: warm-grey neutrals, one green accent, Geist type.
  • Breakpoints follow Tailwind defaults: base = mobile (<768), md = tablet (768–1023), lg = desktop (≥1024).
  • KPI strip on mobile is a 2×2 compact grid, not a horizontal scroller — all four totals are visible at once with no hidden content or swipe affordance.
  • Filters use styled native <select>s: they open the OS picker on phones (best tap ergonomics), cost zero JS, and map 1:1 to Tailwind.
  • "Total collected" = sum of Paid payments to Gymloop. "Active gyms" counts Active status only (trials excluded).
  • Light mode only for v1 — dark mode left out rather than half-done.

Overlays
Desktop modal: centred, max-w 440 (confirm) / 480 (plan form), scale .96→1. Mobile: confirm = bottom sheet with grab handle, buttons stacked (primary on top); plan form & sent detail = full-screen sheet. Sent detail on desktop = right side panel 460px. All: backdrop click + Esc close, focus trapped (focus-trap-react or Headless UI Dialog), focus returns to trigger.
Unsaved changes
Compose is dirty once any field changes. Switching tab or route opens “Discard unsaved changes?” with Keep editing / Save as draft / Discard. Also register beforeunload and React Router’s useBlocker for hard navigation.
Formatting helpers
formatINR(125000) → ₹1,25,000 · formatDate(d) → 24 Sep 2026 (en-GB, day 2-digit, month short) · time → 6:30 PM IST. Status is never colour-only: badges carry text; days-remaining carries text + icon.
